# React Assignment 1–7

A single React + Vite project containing submission-ready demonstrations for Assignments 1–7.

## Run
npm install
npm run dev

## Build
npm run build

## Weather API
For Assignment 4, create a Vercel environment variable named VITE_WEATHER_API_KEY with an OpenWeatherMap API key.

## Routes
/a1 Personal Portfolio
/a2 Student Information
/a3 Employee Directory
/a4 Weather Dashboard
/a5 Shopping Cart
/a6 Task Manager
/a7 Authentication System
